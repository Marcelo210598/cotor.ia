## 📝 Decisões técnicas
- **Prompt IR** guardado como JSON; renderers por alvo; IMAGE é caso especial.
- Score: normaliza sempre pras 10 dimensões canônicas (o judge às vezes
  renomeia/duplica chave). `.length(10)` era rígido demais → `.min(1)` + fill.
- Motor só no Haiku por ora (síntese + judge). Groq plugado, é a alavanca de
  custo/latência pra Fase 5. Modelo Groq default `openai/gpt-oss-120b` (env
  `GROQ_MODEL`) — melhor JSON que o qwen pra tarefas estruturadas.
- Prompts internos versionados no repo (`PROMPT_VERSION` = "2026-09-05.1"),
  gravado em `Score.rubricVersion`.

## ⚠️ Problemas e soluções
- Prisma 7 rejeita `url` no schema → fixado em 6.19.3.
- shadcn base-nova = Base UI, sem `asChild` → `<LinkButton>`.
- sonner.tsx importava next-themes (ausente) → `theme="dark"` fixo.
- Animações quebravam com strict-mode (guard `useRef` + cleanup de timers matava
  a 2ª execução) → removido guard; gauge com flag `cancelled`; visibilidade por
  `setTimeout`.
- eslint `react-hooks/set-state-in-effect` → `useSyncExternalStore` no
  `useReducedMotion`.
- `server-only` não estava instalado → removido dos módulos de IA (comentário no
  lugar; só são importados server-side).
- `TaskType` no Prisma não tinha `IMAGE` → adicionado + `db push`.
- Judge devolvia >10 dimensões → schema `.min(1)` + normalização no engine.
- **Latência**: full run ~40–50s (score ~29s). Aceitável em `maxDuration=60`,
  otimizar depois.
