## 📝 Decisões técnicas
- Prompt IR guardado como JSON; renderers por alvo; IMAGE é caso especial
  (prompt de modelo de imagem + negative, não instrução de LLM texto).
- Score: normaliza sempre pras 10 dimensões canônicas; overall ponderado.
- Divisão de modelo: **analyze + score = Groq** (rápido/barato), **síntese +
  otimização = Haiku** (escrita). Groq é a alavanca de custo/latência.
- Prompts internos versionados (`PROMPT_VERSION` = "2026-09-05.2"), gravado em
  `Score.rubricVersion`.

## ⚠️ Problemas e soluções
- Prisma 7 rejeita `url` no schema → fixado 6.19.3.
- shadcn base-nova = Base UI, sem `asChild` → `<LinkButton>`.
- sonner.tsx importava next-themes (ausente) → `theme="dark"` fixo.
- Animações quebravam com strict-mode → removido guard `useRef`; gauge com flag
  `cancelled`; visibilidade por `setTimeout`; `useSyncExternalStore` no
  `useReducedMotion`.
- `server-only` não instalado → removido dos módulos de IA.
- `TaskType` no Prisma sem `IMAGE` → adicionado.
- Judge devolvia >10 dimensões → schema `.min(1)` + normalização.
- **Better Auth 1.7**: callback OAuth dava `internal_server_error` → faltava
  coluna `issuer` no `Account`.
- **Groq free tier = 8k TPM**: 3 chamadas de score paralelas → 429. Default
  SCORE_SAMPLES=1 + retry em 429 (espera o tempo sugerido, até 12s).
- **Optimize truncava**: IR de prompt complexo passa de 2400 tokens → JSON
  inválido. maxTokens 2400 → 4000.
- Composer não setava `promptId` no fluxo de resultado direto → "Otimizar" não
  disparava.
