## 📝 Decisões técnicas

- **Chave Asaas começa com `$`** → guardar SEM o `$` (`.env` via dotenv-expand E
  Vercel interpretam `$X` como referência de var → some). `apiKey()` recoloca.
- **`process.env` em const de módulo** pode ser inlinada como `undefined` no build
  do Next → usar função que lê em runtime (`billingEnabled()`, `apiKey()`).
- **Checkout hospedado do Asaas só aceita cartão** → usei a Subscriptions API +
  `invoiceUrl` da 1ª cobrança pra ter Pix. Asaas exige CPF pra criar customer.
- **Webhook sempre 200** (exigência do Asaas — erro pausa a fila).
- **Galeria: forçar taskType** no seed (o analyzer não respeita a categoria que
  eu quero; e IMAGE precisa da categoria certa pro `renderImage`).
- Função Vercel + banco na mesma região = regra de ouro (o resto de perf é detalhe).
